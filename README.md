## 📋 Project Overview

This project performs a comprehensive **Exploratory Data Analysis (EDA)** 
on a real-world E-Commerce Sales Dataset containing over **4,36,000 
transactions** across **38 countries**, generating nearly **£9 Million** 
in total revenue.

The analysis extracts meaningful business insights, identifies patterns 
and trends, and generates actionable recommendations using 
industry-standard data science techniques.
